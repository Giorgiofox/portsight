# Attribution

CablePro is a personal project for Apple Silicon USB-C cable diagnostics.

It reuses the **MIT-licensed** data layer from
[WhatCable](https://github.com/darrylmorley/whatcable) by Darryl Morley,
unmodified, under the following module directories:

- `Sources/WhatCableCore`
- `Sources/WhatCableDarwinBackend`
- `Sources/WhatCableAppKit`

The full MIT license text for that code is preserved in `LICENSE-whatcable`.

The proprietary `WhatCablePlugins` module (all rights reserved) is **not**
included, referenced, or reused in any form. All "pro" feature presentation
in CablePro is written from scratch on top of the public MIT data models.
